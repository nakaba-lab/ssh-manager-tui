# 用語集（sshm-tui）

業務用語（日本語）→ 英語識別子の対訳辞書。**同一概念に複数の英語名（訳語のブレ）を生まない**ための正の辞書であり、ローマ字識別子禁止（`post_edit.py` が検知）の受け皿。新しい業務概念を命名したらここに追記してから使う。コードベースは英語識別子で書くため、本表は「日本語で語られる概念 → 実装で使う英語名」の対応を固定する。

| 用語（日本語） | 英語名（識別子） | 使用箇所・備考 |
|--------------|----------------|--------------|
| ホスト / エイリアス | host / alias | `~/.ssh/config` の `Host` エントリ。`HostView.alias()` |
| ホスト名 | host_name（`HostName`） | 接続先の実アドレス。config の `HostName` |
| 踏み台 / ジャンプホスト | proxy jump（`ProxyJump`） | `HostView::is_proxied`。プロキシ経由は到達性 `Skipped` |
| ポート転送 | port forwarding（local/remote/dynamic forward） | `LocalForward`/`RemoteForward`/`DynamicForward` |
| 接続 | connect | `os/connect.rs`。保存済みは `ssh <alias>` |
| 無損失往復 | lossless round-trip | `render(parse(s)) == s`。config 層の中核不変条件 |
| 外科的書き込み | surgical write | 変更行のみ書き換える保存。`writer.rs` の `set_single`/`set_multi`/`set_extras` |
| 差分プレビュー | diff preview | 保存前の行レベル差分。`config/diff.rs`・`ui/diff.rs` |
| 到達性 | liveness / reachability | 背景プローブ。`os/liveness.rs`。`up`/`down`/`checking`/`skipped`/`unknown` |
| 保管庫 | vault | 暗号化秘密ストア `~/.ssh/sshm-vault.json`。`os/vault.rs` |
| 秘密 | secret | ログインパスワード・鍵パスフレーズ。`Secret`（zeroize） |
| マスターパスワード | master password | vault 復号鍵の素。Argon2id で伸長。永続化しない |
| オートフィル | autofill | 接続時に vault の秘密を SSH_ASKPASS 経由で解放。`os/askpass.rs` |
| 信頼ゲート | trust gate | オートフィル解放の門番。System32 OpenSSH を `is_system32` で検証 |
| 鍵ペア | key pair | 公開/秘密鍵。フィンガープリント照合で `PairStatus` |
| 既知ホスト | known_hosts | `os/known_hosts.rs`。内容アドレスで削除 |
| 実効設定インスペクタ | effective config inspector | `ssh -G` の解決結果を表示する画面。`Screen::Inspect`・`ui/inspect.rs`・`os/resolve.rs::resolve_full`（#43） |
| 実効設定 | effective config | ワイルドカード/`Match` 適用後に実際に効く設定。`ssh -G` の出力（正規化された近似） |
| 接続履歴 | connection history | `~/.ssh/sshm-history.json`。alias→最終接続時刻 |
| 設定（非秘密） | preferences（prefs） | `~/.ssh/sshm-prefs.json`。オートフィル opt-in 等 |
| パスフレーズ | passphrase | 秘密鍵を保護する語句。vault では `SecretKind::Passphrase` |
| 陳腐化（した秘密） | stale (secret) | 鍵のパスフレーズ変更で vault の保存値が古くなった状態。`stale_passphrase_hosts` |
| パスフレーズ同期 | passphrase sync | 陳腐化したエントリを新パスフレーズで一括更新する操作。`Screen::PassphraseSync`・`PassphraseSyncForm` |
| Include 展開 | include expansion | `Include` で分割された config を再帰展開して一覧に載せる（read-only）。`config/includes.rs::expand`（#52） |
| included ホスト | included host | `Include` 先ファイルのホスト。閲覧専用の投影 `IncludedHost`・`HostRef::Included`（#52） |
| 先勝ち（重複エイリアス） | first-wins (shadowed) | 同名エイリアスは先に定義した方が有効。included 側の重複は `IncludedHost.shadowed` として一覧に `⊘` 表示（#52） |
