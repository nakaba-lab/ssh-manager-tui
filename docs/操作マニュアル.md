# 操作マニュアル（sshm）

エンドユーザー向けの操作手順。**キーバインドの網羅一覧・機能詳細は [README](../README.md) が真実源**（重複を避けるため本書は導線と FAQ に絞る）。

## はじめに

`sshm` は `~/.ssh/config` のホストを閲覧・編集・接続するターミナル UI（TUI）。インストールは [README のインストール節](../README.md#installation)（crates.io / Scoop / winget / プリビルドバイナリ）を参照。

## 基本操作

```text
sshm                 対話的な TUI を起動（~/.ssh/config に対して）
sshm --list          ホスト一覧を出力して終了（非対話）
sshm --config PATH   別の config ファイルを使う（安全なお試しに便利）
```

- 一覧で `j`/`k` 移動・`/` 検索・`Enter` 接続・`e` 編集・`a` 追加・`?` ヘルプ。
- 編集後は**保存前に差分（diff）が表示**され、承認して初めて `~/.ssh/config` に書き込まれる（変更行のみ・コメントや書式は保持）。
- 主要画面: 鍵マネージャ（`K`）・known_hosts（`H`）・パスワード保管庫（`P`）・SFTP ブラウザ（`b`）。

## よくある質問（FAQ）

- **編集して大丈夫？** 編集していない行はバイト単位で保持され、保存前に差分を確認できる。初回保存時に `config.bak` バックアップも作られる。
- **パスワードはどこに保存される？** 暗号化された保管庫（`~/.ssh/sshm-vault.json`）。SSH config には決して書かれない。マスターパスワードで保護。
- **Windows で「保護されました」警告が出る** 自己署名バイナリのため。詳細は [README のダウンロード節](../README.md#download-a-prebuilt-binary)。
